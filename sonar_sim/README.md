# sonar_sim — 가상 사이드스캔 소나(SSS) 시뮬레이터

가상 해저 공간(지형, 퇴적물, 암석, 물체)을 만들고, 그 위를 지나가는 SSS 의 영상을 물리 기반으로 생성합니다.
실제 소나처럼 스페클, 열잡음, 수면반사, 다중경로, 간섭, 핑 누락, 차체 흔들림이 들어갑니다.
노이즈 영상과 함께 **정답(기대 강도) 영상과 라벨**을 저장하므로, 필터 검증이나 학습 데이터로 쓸 수 있습니다.

## 실행 (PowerShell, 이 폴더에서)

```powershell
python -m pip install -e ".[dev]"
python -m pytest                                        # 13 tests, 약 7초
python run_sim.py                                       # scenes/default.json -> results/<타임스탬프>/
python run_sim.py --scene scenes/wreck_site.json        # 다른 장면
python run_sim.py --random 100 --no-figure              # 무작위 장면 100장 (장당 약 8~12초)
python make_scenes.py                                   # 예제 장면 JSON 재생성
```

출력 (장면 하나당):
- `*_noisy.png` / `*_clean.png`: 화소 1:1 영상 (dB, 기본 -18 ~ +10 dB, 컬러맵 `sonar` 또는 `--cmap gray`)
- `*.npz`: `intensity`, `clean` (선형 강도 float32, 모래 평균 ≈ 1), `label_object_id`, `label_object_shadow_id`, `label_shadow`, `label_seafloor`, 축 (`across_m`, `along_m`), 항법 (`nav_*`)
- `*.json`: 사용한 설정 전체 (재현용) + 메타데이터
- `*_quicklook.png`: 해저 지도와 항적, 노이즈 영상, 정답 영상, 라벨, 차체 운동을 한 장에 모은 4면 그림

영상 열 순서는 `[좌현 먼 거리 … 가까운 | 우현 가까운 … 먼 거리]` 이고, 행은 핑(시간) 순서입니다.

## 예제 장면 (`scenes/`, 결과는 `docs/`)

| 장면 | 내용 |
|---|---|
| `default` | 원통(기뢰형), 구, 상자, 반매몰 원통 |
| `wreck_site` | 상자로 만든 선체+상부구조+돛대, 잔해, 자갈/암석 많은 해저 |
| `pipeline_shallow` | 얕은 바다(수심 9 m)에 매몰된 파이프라인. 수면반사와 다중경로가 강함 |
| `rough_survey` | 큰 롤/요/히브, 낮은 SNR, 간섭, 핑 누락, 빔보정 없음 |

장면은 JSON 으로 편집합니다. 물체 종류는 `cylinder | box | sphere` 이고 위치, 크기, 방위, 매몰 깊이, 반사율, 정반사 강도를 정합니다.
모르는 키는 오류를 냅니다 (오타 방지).

## 좌표계
- 월드: ENU (x = 동, y = 북, z = 위), 해저 기준면 z = 0.
- `heading`: +x 축에서 반시계 방향 [deg].
- 우현 = 진행방향의 오른쪽 (위에서 볼 때).
- roll > 0 = 우현 아래, pitch > 0 = 기수 위.

## 물리 모델 (`sss_sim/`)

| 모듈 | 내용 |
|---|---|
| `config.py` | 모든 파라미터 (dataclass) ↔ JSON |
| `seabed.py` | 멱법칙 스펙트럼 지형 P(k) ∝ k^−β, 휘어진 비대칭 모래물결 (국지적), 퇴적물 (모래/진흙/자갈, 점진 경계), 감마 텍스처 (K-분포형 꼬리), 불규칙 암석, 물체 래스터화 |
| `trajectory.py` | 직선 항로를 핑 주기로 표본화. 히브/롤/피치/요 = 주기 성분 + 저주파 랜덤 |
| `acoustics.py` | 핑마다 빔 평면과 지형의 교선 (피치 반영), 람베르트 cos²θ + 물체 정반사, 고각 누적최대로 그림자, 수직 빔패턴 (롤 반영, 사이드로브 바닥), r⁻⁴ 확산 + 흡수, TVG, 경사거리 bin 누적. 수면 산란, 수면 1회 반사 다중경로 (거울상 소나, 등가거리 (r + r_m)/2) |
| `noise.py` | 복소 신호 Z = (√I₀·w) ⊛ g + n. 거리 해상도 c·τ/2. **진행방향 해상도 ∝ 거리 (R·θ_h)**. 열잡음은 TVG 로 거리와 함께 증가. 간섭 줄무늬, 핑 누락 |
| `sonar.py` | 전체 조립. 평탄 해저 기대응답으로 빔패턴/TVG 를 보정 (끌 수 있음 → 밴딩이 보임). 수주 체적산란, 물고기/부유물 |
| `randomize.py` | 도메인 랜덤화 (고도, 수심, 운동, 지형, 퇴적물, 물체, 잡음, 간섭 등) |
| `display.py` | dB/8-bit 변환, 소나 컬러맵, 저장, 4면 그림 |

## 검증한 것 (`tests/test_sim.py`)
- 첫 해저 반사 거리 = 고도이고, 그 앞은 수주(0)이다.
- 빔 보정 후 평탄 모래 강도 = 1 (±2%).
- 평탄 해저에서 좌현과 우현의 정답 영상이 대칭이다.
- 상자 표적의 그림자 시작/끝 거리가 기하 해석해 y·H/(H−h) 와 3 bin 이내로 일치한다. 물체 라벨과 그림자 라벨이 함께 생긴다.
- 스페클: 강도/정답 평균 = 1 (±3%), ENL = L (L = 1, 4; ±12%).
- 진행방향 점 응답의 폭이 거리에 비례한다.
- 다중경로 유령이 수심 D 에 해당하는 거리부터 나타난다 (수직 아래 해저점의 경로 (H + 2D − H)/2 = D).
- 얕은 견인에서는 수면 반사가 첫 해저 반사보다 먼저 나온다.
- 같은 seed 면 같은 영상, seed 가 다르면 다른 영상.
- 무작위 장면이 유효하고, 운동과 아티팩트가 켜져도 NaN 이나 음수가 없다.

## 한계 (중요)
- **2.5D 높이맵**이다. 돌출부 아래 공간(오버행)이나 물체 내부는 표현할 수 없다. 단일 산란이고, 수면 1회 반사 외의 다중 반사는 없다.
- 기본 장비 파라미터(400~500 kHz 급, 흡수 0.1 dB/m, 빔폭)는 대략값이며 특정 장비가 아니다 (확인 필요).
- 지형 스펙트럼 지수 β, 텍스처 분포, 수면/체적 산란 수준은 그럴듯한 값을 넣은 것이지, 실측으로 맞춘 값이 아니다.
- **실제 소나 영상과 정량 비교를 하지 않았다.** "실제처럼 보이는지"는 눈으로만 판단했다.
- 진행방향 빔 발자국은 "중앙선 표본 + 진행방향 PSF 컨볼루션"으로 근사했다.
- 다중경로 경로의 입사각과 그림자는 직접 경로 값을 그대로 쓴다 (간이 모델).
- 속도: 장면 1장(400 ping × 1024 bin)에 약 8~13초 걸린다. 대부분 해저 생성 시간이다. 1000장이면 약 3시간이다.
