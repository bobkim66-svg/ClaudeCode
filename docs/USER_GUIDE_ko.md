# 음파 중첩 입자 궤적 편광 시뮬레이터 — 사용자 가이드

## 0. 3D 소나 탭 (수중 소나 3D 시뮬레이션, CAD 뷰)

물속에서 소나 송신기가 만든 음파에 **물 입자가 어떻게 움직이는지** 3D 로 봅니다. AUV 몸체·해저 바닥·바위 같은 물체에서
반사·회절되는 것도 포함합니다. 첫 번째 탭입니다.

### 사용 순서

1. **예시 불러오기**: `AUV + 앞쪽 소나 (연속파)`, `해저 위 하향 소나 핑`, `4소자 배열 빔 조향`, `배플 피스톤 (해석해 검증용)`.
2. **물체 표** (회색): 종류(직육면체·원기둥·구·STL), 중심 x, y, z [m], 크기, 방향(방위각·고각).
   - 크기: 직육면체 = 길이·폭·높이, 원기둥 = 길이·지름, 구 = 지름, STL = 배율 (mm 로 그린 파일이면 0.001).
   - 방위각 = x 축에서 반시계 [°], 고각 = 수평면에서 위로 [°]. 물체의 국소 x 축(원기둥 축)이 그 방향을 향합니다.
   - **STL 불러오기…**: CAD 에서 내보낸 STL (바이너리/ASCII). 닫힌 솔리드여야 내부가 채워집니다 (구멍이 있으면 경고).
3. **송신기 표** (주황 원판, 화살표 = 방사 방향): 중심, 방향, 지름, 두께, 진폭 ξ0, 위상, 지연.
   - 앞면만 피스톤처럼 진동합니다 (변위 ξ0 cos(ωt − φ)). 뒷면과 옆면은 강체.
   - 여러 개를 놓고 위상을 차례로 바꾸면 빔이 꺾입니다 (배열 예시: 간격 λ/2, 위상차 +90° → sin θ = Δφ/(kd) = 0.5, 약 30°).
4. **신호**: 연속파(정상상태) 또는 핑(펄스, 주기 수 지정).
5. **계산 영역과 흡수 경계**: 체크한 면은 파가 빠져나가는 넓은 바다, 끄면 그 면이 강체 벽입니다 (예: `z− (바닥)` 끄기 = 해저).
6. **파장당 셀 수**: 10 = 화면 확인용 (위상속도 오차 약 1.6%), 16 이상 = 정밀 (시간 약 4배 이상). 예상 시간이 표시되며
   5분이 넘으면 빨간 글씨로 알려 줍니다.
7. **계산 실행** → 진행률 표시, [취소] 가능. 끝나면 자동 재생.

### 3D 뷰 조작 (CAD 와 비슷)

- 왼쪽 드래그 = 회전, 휠 = 확대/축소, 가운데 드래그(또는 Ctrl+왼쪽) = 이동.
- 위쪽 단추: 등각 / 정면(−y 에서) / 윗면(+z 에서) / 측면(+x 에서) / 화면 맞춤.
- **단면**: x, y, z 단면을 켜고 슬라이더로 위치를 옮깁니다. 색 = 순간 음압 (빨강 압축, 파랑 팽창, 0 근처는 반투명) 또는
  음압 진폭 |p| (dB 눈금 권장: 멀어질수록 1/r 로 약해지기 때문).
- **물 입자** (점): 평형 위치 + 변위 × 확대. 실제 변위는 마이크로미터 이하라 보이도록 확대합니다
  (`확대 %` = 가장 크게 움직이는 입자의 화면 변위가 입자 간격의 몇 %인지). 점 색 = 그 위치의 순간 음압.
  `단면 위 입자만` 이 보기 편하고, `전체 3D 격자` 는 공간 전체를 봅니다.
- **핑**: 펄스가 퍼지며 약해지므로 기본으로 `프레임마다 색 범위·확대 자동` 이 켜져 있습니다 (끄면 실제 크기 비례).
  핑의 순간 단면은 계산할 때의 슬라이더 위치에서 기록되므로, 위치를 바꾸려면 다시 계산하세요
  (진폭/최대 모드는 아무 위치나 바로 됨).
- **결과 저장**: 3D 화면 PNG, 설정 JSON (STL 은 상대경로), 요약 HTML, 입자별 최대 변위·음압 CSV.

### 모델

- 3D 선형 음향 (이상 유체), 엇갈림 격자 시간 영역 유한차분 (FDTD). 엔진 B (2D) 를 3D 로 확장한 것입니다.
  ∂v/∂t = −∇p/ρ, ∂p/∂t = −ρc² ∇·v. 물체는 강체 (법선 속도 0). 바깥은 흡수층 (PML).
- 엇갈림 격자라 이산 회전(∇×v)이 구조적으로 0 입니다. 물속 입자는 언제나 **종파 운동**을 합니다
  (요약의 회전 검증 값이 float32 반올림 수준 ~1e-6 이면 정상).
- 기울어진 송신기·물체는 격자 위에서 계단 모양으로 근사됩니다 (셀 크기 정도의 위치 오차).
- 연속파: 켜짐 3주기 + 영역을 2번 가로지른 뒤 정수 주기 평균으로 정상상태 진폭·위상을 구합니다 (요약의 '창 차이' 가
  작으면 정상상태 도달).

### 주의할 점 (결과 해석)

- **소진폭 선형**: 진폭을 키워도 모양은 같고 크기만 비례합니다. 화면 움직임은 진폭이 아니라 `확대 %` 로 키우세요.
  k·u > 0.1 이면 경고합니다. 음압이 1 bar 를 넘으면 실제 물에서는 캐비테이션 가능성을 알립니다.
- 흡수, 수온·염분에 따른 음속 변화, 해수면(압력 해방 경계), 탄성 해저(전단파)는 없습니다. 해저 바닥은 완전 반사 강체입니다.
- 격자가 커지면 메모리·시간이 셀 수에 비례합니다 (약 20~30 ns/셀·스텝, 첫 계산 뒤 실측 속도로 견적 갱신).
  예: 3 × 2 × 2 m, 5 kHz, 파장당 10 셀 ≈ 100만 셀, 약 15~25 초.
- 파장당 셀 수를 바꿔도 결과가 같은지 확인하면 이산화 오차를 직접 볼 수 있습니다.

## 1. 무엇을 보여 주는가

소리(공기 중 음파)는 **종파**입니다. 평면파 하나에서 공기 입자는 전파 방향 k̂ 를 따라 앞뒤로만 진동하므로 "편광"이 없습니다.
그런데 방향이 다른 음파 여러 개가 겹치면, 한 지점의 입자가 받는 변위는 서로 다른 방향의 진동의 합이 되어
궤적이 **직선이 아니라 타원이나 원**이 될 수 있습니다. 이 프로그램은 그 **국소 입자 궤적의 모양(편광)** 을 정량화합니다.

### 이 시뮬레이션이 보여 주지 않는 것 (중요)

- **횡파가 생긴 것이 아닙니다.** 이상 유체에는 전단 복원력이 없어 횡파가 전파되지 않습니다.
  변위장은 항상 비회전(∇×u = 0)이고, 프로그램은 이를 수치로 확인해 화면에 표시합니다.
  타원 궤적은 "서로 다른 방향의 종파 진동의 합"일 뿐입니다.
- **입자는 이동하지 않습니다.** 각 점은 평형 위치에 고정된 추적자이며 변위 u(r,t) 만큼 진동합니다.
  실제 변위(기본 1 µm)는 격자 간격(수 cm)보다 수만 배 작아서, 화면에서는 **시각 배율**로 확대해 그립니다.
- 용수철로 연결한 질점 격자 모델은 쓰지 않습니다 (전단 강성이 생겨 가짜 횡파가 전파되기 때문).

## 2. 물리 모델 (엔진 A: 평면파 해석해)

선형 음향, 소진폭, 이상 유체 가정. 소스 m 의 변위:

    u(r,t) = Σ_m A_m k̂_m cos( k_m·(r − r_m) − ω_m t + φ_m ),   k_m = (ω_m / c) k̂_m

- 입자 속도 v = ∂u/∂t, 음압 p = −ρc² ∇·u (모두 해석적으로 계산)
- 시간평균 음향 세기 I = ⟨p v⟩. 평면파 하나면 I = ½ ρ c ω² A² k̂
- 변위가 k̂ 와 평행하므로 각 항은 퍼텐셜의 기울기 → ∇×u = 0 이 해석적으로 성립
- 기본값: c = 343 m/s, ρ = 1.2 kg/m³, f = 1000 Hz (파장 0.343 m). 무차원 모드는 c = 1, ρ = 1 (f = 1 이면 파장 1)

### 가우시안 빔 (유한 폭 빔)

평면파는 공간 전체에 퍼져 있어 "교차 영역"이 따로 없습니다. 교차 영역을 국소화하려면 소스 종류를
**가우시안 빔**으로 바꾸세요. 허리 반경 w0 인 빔을 평면파 여러 개(각스펙트럼 ∝ exp(−k_t² w0²/4))의 합으로
만들기 때문에, 각 성분이 정확한 평면파이고 **∇×u = 0 과 파동방정식을 정확히 만족**합니다.
초점(기준점)에서 빔 단면 진폭은 exp(−ρ²/w0²) 입니다.

주의: 각스펙트럼을 유한 개로 표본화했기 때문에 빔이 횡방향으로 주기 2π/Δk_t 마다 **가짜로 반복**됩니다.
관측 영역이 그 반복에 닿으면 경고가 뜹니다 (각스펙트럼 표본 수를 늘리면 주기가 길어짐).
w0 < 파장이면 근축 근사가 깨져 단면이 가우시안과 달라진다는 경고가 뜹니다.

## 3. 정량 지표 (입자마다, 시간창 평균)

궤적 공분산 C = ⟨(u − ū)(u − ū)ᵀ⟩ 의 고유값 λ1 ≥ λ2 ≥ λ3 로부터:

| 지표 | 정의 | 해석 |
|---|---|---|
| 직선성 L | 1 − λ2/λ1 | 1 = 직선 진동(순수 종파적), 0 = 원 |
| 타원도 e | √(λ2/λ1) | 1 = 원 궤적, 0 = 직선 |
| 평면성 | 1 − λ3/λ2 | 1 = 궤적이 한 평면에 갇힘 |
| 횡성분율 T | ⟨\|u − (u·Î)Î\|²⟩ / ⟨\|u\|²⟩ | 에너지 흐름 방향 Î = I/\|I\| 에 수직인 진동 성분의 비율 |
| RMS 변위 | √⟨\|u\|²⟩ | 간섭 무늬 (보강/상쇄) |
| \|I\| | 시간평균 세기의 크기 | 에너지 흐름의 세기 |

### 회색(NaN) = 정의 불가

임의 값으로 채우지 않고 회색으로 표시합니다.

- **변위 마디** (λ1 ≈ 0): 궤적이 없으므로 L, e, 평면성, T 모두 정의 불가
- **직선 궤적** (λ2 ≈ 0): 평면성이 0/0 → 정의 불가
- **세기 ≈ 0** (정재파, 소용돌이 중심): 기준 방향 Î 가 없으므로 T 정의 불가

### T 를 해석할 때 주의

T 가 크다고 "횡파"가 아닙니다. 예: 직교 2파 프리셋에서 δ = π 근처의 입자는 (1,−1) 방향으로 **직선** 진동하지만
에너지는 (1,1) 방향으로 흐르므로 T → 1 이 됩니다. 그 지점은 세기 자체가 0 으로 가는 곳이라 Î 가 불안정합니다.
T 는 반드시 |I| 맵과 함께 보세요.

### 회전 검증 표시

화면 오른쪽 아래 정보창에 max|∇×u| / max|∇u| 가 표시됩니다 (3D 중앙차분, 간격 = 최소 파장/1000).
정상값은 0 ~ 10⁻⁵ 수준 (차분 절단오차)이며 10⁻⁴ 이상이면 빨간색으로 "구현 오류 의심"이 뜹니다.
엔진 A 에서는 해석적으로 0 이므로 이 값은 **물리 증거가 아니라 구현 버그 검출기**입니다.

### 시간창

- **자동**: 모든 주파수의 공통 주기 (예: 1000 Hz + 1100 Hz → 10 ms). 비가 무리수이거나 50 주기보다 길면 수동 길이 사용.
- **주파수가 섞이면 맥놀이** 때문에 순간 궤적 모양이 시간에 따라 변합니다. 지표는 창 전체의 평균이며,
  창을 짧게 잡으면 결과가 크게 달라집니다 (경고가 표시됨).

## 4. 화면 구성과 조작

| 영역 | 내용 |
|---|---|
| 왼쪽 패널 | 프리셋, 소스 표, 매질, 관측 평면, 시간창, 표시 설정 |
| 왼쪽 위 그림 | 관측 평면의 입자 애니메이션. 회색 작은 점 = 평형 위치, 큰 점 = 현재 위치(배율 적용), 점 색 = 음압 (빨강 = 압축·뭉침, 파랑 = 팽창·흩어짐; '점 색' 에서 평면 밖 변위로 바꿀 수 있음) |
| 오른쪽 위 그림 | 선택한 지표 맵 (+ 세기 흐름 화살표 선택 가능). 회색 칸 = 정의 불가 |
| 아래 그림 | 선택 입자의 실제 변위 궤적 (배율 없음), 평면 기저 (u, v, n) 의 세 투영 |
| 오른쪽 아래 | 회전 검증, 시간창, 격자, 경고, 프리셋 예상 결과 |

- **입자 선택**: 애니메이션이나 지표 맵에서 클릭하면 가장 가까운 입자가 선택됩니다 (빨간 원/사각형).
- **3D 궤적 창**: OpenGL 3D 보기 (빨강 u, 초록 v, 파랑 n 축). 그래픽 드라이버가 OpenGL 을 지원하지 않으면 안내가 뜨며, 2D 투영은 그대로 사용 가능합니다.
- **결과 저장**: 선택한 폴더 아래 `polarsim_날짜_시각` 폴더를 새로 만들어 저장합니다 (덮어쓰지 않음).
  - `metrics.csv`: 입자별 지표 (UTF-8 BOM, Excel 에서 한글 바로 열림, 정의 불가는 `nan`)
  - `config.json`: 재현용 전체 설정 (위상은 rad)
  - `summary.txt`: 회전 검증, 지표 범위, 경고
  - `plane.png`, `map_<지표>.png`, `trajectory.png`: 폭 1800 px

### 입자가 뭉치고 흩어지는 모습 키우기

화면의 입자 위치는 평형 위치 + 시각 배율 g × 실제 변위입니다. 화면에서 입자가 뭉치는 정도는 국소 면적비
det(I + g∇u) 로 정해집니다 (1 보다 작으면 뭉침, 크면 흩어짐, 0 이하면 이웃 입자를 지나쳐 보이는 착시).

- **'뭉침 강도' (기본 60%)** 를 올리세요. 자동 배율이 '화면 면적이 최대 ±강도 만큼 변하도록' 정해집니다
  (정재파에서 60% → 면적 40% ~ 160%). 80~90% 가 가장 극적이고, 100% 근처부터 입자가 겹쳐 보이면 빨간 경고가 뜹니다.
- **진폭을 키우는 것은 효과가 없습니다.** 선형 모델이라 자동 배율이 그만큼 줄어 화면이 같습니다. 게다가 진폭이
  파장에 비해 커지면 (k·A > 0.1) 소진폭 가정이 깨져 결과가 물리적으로 무의미하며, 경고가 뜹니다. 실제 공기 중 소리의
  변위는 µm 수준입니다 (기본 1e-6 m).
- 점 색을 **음압** 으로 두면 뭉치는 곳(빨강)과 흩어지는 곳(파랑)이 색으로도 보입니다 (∇·u = −p/(ρc²)).
- 재생 속도를 0.2~0.3 주기/초로 낮추면 따라가기 쉽습니다. 엔진 B 탭에도 같은 '뭉침 강도' 가 있습니다.

## 5. 프리셋 3종: 예상 결과와 실제 결과

| 프리셋 | 해석적 예상 | 프로그램 결과 (검증됨) |
|---|---|---|
| ① 정면 대향 2파 → 정재파 | u = 2A x̂ sin(kx) sin(ωt). 마디 간격 λ/2, 모든 입자 직선 진동, I = 0 | L = 1 (마디는 NaN), T 전 영역 NaN(회색), 마디 간격 λ/2 |
| ② 직교 2파 + 90° → 원 궤적 | 원점 u = A(cos ωt, sin ωt, 0). 상대위상 δ = k(y−x)+π/2 를 따라 직선↔원 줄무늬. I = I0(1+cos δ)(x̂+ŷ) | 원점 e = 1, L = 0, T = 0.5. e 맵이 해석식 √((1−\|cos δ\|)/(1+\|cos δ\|)) 와 4×10⁻¹⁵ 이내로 일치 |
| ③ 같은 평면 120° 3파 → 육각 무늬 | 육각 간섭 무늬, 간섭 교차항이 만드는 세기 소용돌이 격자 | 아래 참고 |

**③ 의 상세 (처음 예상을 수정한 부분)**: 원점은 Σk̂ = 0 이라 **변위 마디**이고 세기 흐름은 그곳에서 **안장점**입니다
(처음에는 원점을 소용돌이 중심으로 예상했으나 계산 결과 틀렸음). 실제 소용돌이 중심은 (0, ±2λ/(3√3)) 등이며,
그곳에서 세 파의 위상이 0, ±2π/3 이 되어 **3상 모터처럼** |u| = 1.5A 인 정확한 원 궤적(e = 1)이 됩니다.
그 점에서는 I = 0 이라 T 는 정의 불가이고, 이웃한 소용돌이는 회전 방향이 반대입니다.
"세기 흐름 화살표"를 켜고 타원도 맵을 보면 원 궤적(e ≈ 1, 노랑) 주위를 화살표가 도는 모습을 볼 수 있습니다.
단, 기본 격자(λ/10)에서는 무늬가 거칠어 잘 안 보이므로 **격자 간격을 λ/40 (1 kHz 에서 0.0086 m), 41×41** 정도로
줄여서 보세요. 화살표는 선분이고 끝의 점이 머리(흐름 방향)입니다.

참고: 기본 격자 간격(λ/10)에서는 ② 의 줄무늬가 5 칸 주기라 계단처럼 보입니다. 앨리어싱이 아니라 해상도 문제이며,
간격을 줄이면 매끄러워집니다.

## 5-1. 엔진 B: 로봇 프레임(AUV 품) 방사 — 벽·반사·회절 포함

엔진 A 는 무한 평면파의 합이라 소스가 공간 전체에 있습니다. "로봇 품 안에서만 파를 쏘면 품 밖에서도
그 궤적이 유지되는가?" 를 보려면 소스가 **벽면에만** 있고 벽에서 **반사·회절**되는 모델이 필요합니다.
평면파에 창(window)을 씌워 범위만 자르는 방법은 쓰지 않았습니다. 창의 경계에서 ∇×u ≠ 0 이 되고 파동방정식도
깨지기 때문입니다 (가짜 횡파).

### 모델

- 2D (판이 z 방향으로 무한히 길다고 가정), 이상 유체 (기본: 물 c = 1500 m/s, ρ = 1000 kg/m³)
- 형상: 뒷벽(AUV 몸체 앞면) + 윗판 + 아랫판 = 삼면이 막힌 박스, 입구는 +x 쪽. 벽은 강체
- 소스: 박스 안쪽 각 면이 피스톤처럼 진동 (면 변위 ξ0 cos(ωt − φ), 면마다 켜기·진폭·위상)
- 바깥 경계: 흡수층(PML). 반사율 약 10⁻⁶ (측정됨)
- 풀이: **주파수 영역 정상상태** (엇갈림 격자 위 압력-속도 방정식을 희소 직접법으로 한 번에). 보통 수 초.
  같은 격자의 시간 영역 FDTD 로 교차검증했습니다 (차이 0.1% 이하).

### 검증된 것

| 검사 | 결과 |
|---|---|
| 평면파 (폭 전체 피스톤) vs 해석해 | 위상속도 오차 0.4% (예상 (π/20)²/6), 진폭 = cos(π/20) (셀 평균 효과) |
| FDTD 정상상태 vs 주파수 영역 해 | 열린 판: < 10⁻³, 품 (2700 Hz): 0.09% |
| 에너지 보존 (방사 일률 = 닫힌 경로 밖 세기 플럭스) | 비 1.000 ~ 1.001 |
| ∇×u | 10⁻¹⁵ 수준 (엇갈림 격자에서 구조적으로 0) |
| 대칭 (윗판·아랫판 같은 위상 → y 대칭), 중첩 원리 | 10⁻⁹ 이내 |
| PML 근처 오염 | 작은/큰 영역 해 비교 차이 2×10⁻⁶ |

### 결과: 품 밖에서 타원 궤적은 유지되는가?

기본 형상 (깊이 1 m, 간격 1 m, 판 두께 0.1 m), 2400–3300 Hz, 각 면 진폭 10 µm 에서
(재현: `python -m analysis.pocket_radiation`):

1. **품 안**은 3면 방사일 때 타원 궤적이 뚜렷합니다 (e 중앙값 0.29–0.34). 뒷벽만 방사하면 약 0.03 (거의 직선).
   예외: 차단 주파수 공진(3000 Hz) 에서는 공진한 횡모드가 지배해 품 안도 거의 직선 (0.04) 입니다.
2. **품 밖**에서는 입구에서 멀어질수록 타원도가 줄어 **거의 직선 진동(종파)** 으로 돌아갑니다.
   에너지 가중 e: 2–4λ 약 0.09 → 4–8λ 약 0.05 → 8–12λ 약 0.03 (거리가 2배일 때 약 0.55–0.6배, 원거리 이론 1/(kr) 에 접근).
3. **품 밖 타원도는 옆판 방사와 거의 무관합니다.** 뒷벽만 방사한 경우와 품 밖 값이 거의 같습니다
   (예: 2700 Hz, 2–4λ 에서 0.085 vs 0.095). 품 밖에 남는 약한 타원도는 입구 가장자리의 **회절** 때문이며,
   단순한 종파 피스톤도 똑같이 만듭니다. 즉 품 안의 타원 궤적은 **밖으로 전달되지 않습니다**.
4. 품 밖 에너지 흐름 방향 기준 횡성분율 T 중앙값은 0.001–0.03 입니다. 에너지는 종파로 나갑니다.
5. 지향성 영점 방향(빔 옆 비스듬한 선)에는 e 가 큰 좁은 선이 남지만, 그곳은 진폭이 거의 0 인 곳입니다.

### 로봇 프레임 직접 만들기 (막대 편집기)

엔진 B 탭 왼쪽 **'로봇 프레임'** 표에서 막대(판)를 원하는 개수(최대 12개)·각도로 배치합니다.
표를 고치면 그림에 바로 미리보기가 나옵니다 (계산 전에도).

| 열 | 뜻 |
|---|---|
| 이름 | 표시용 이름 (공진 경고 등에 쓰임) |
| x1, y1 | 끝점 1 [m] |
| x2, y2 | 끝점 2 [m]. 고치면 각도·길이가 자동 계산 |
| 각도 [°], 길이 | 끝점 1 에서 본 방향 (x 축에서 반시계) 과 길이. 고치면 끝점 2 가 자동 계산 |
| 두께 | 막대 두께 [m] (중심선 양쪽으로 절반씩) |
| 방사면 | 없음(그냥 벽) / 왼쪽 면 / 오른쪽 면 / 양쪽 면. **끝점 1 → 끝점 2 로 걸을 때** 왼쪽·오른쪽 |
| 진폭 ξ0, 위상 | 방사면의 변위 진폭 [m] 과 위상 [°]. 면에 수직으로 진동 |

- **그림 읽기**: 회색 = 막대, 주황 선 = 방사 면, 주황 화살표 = 방사 방향, 빨간 테두리 = 표에서 고른 막대,
  빨간 + 와 화살표 = 거리 통계 기준점과 '앞쪽' 방향.
- **버튼**: 추가 / 복제 (조금 아래로 옮긴 사본) / 삭제 / 위로·아래로 / 끝점 뒤집기 (방사면도 함께 바꿔 같은 면 유지).
- **예시 불러오기**: 기본 품, 기울어진 V자 (±20°), 품 + 안쪽 지느러미, 기울어진 판 하나. 예시를 불러온 뒤 고쳐 쓰면 쉽습니다.
- **파일로 저장 / 불러오기**: 막대 목록과 계산 영역·기준점을 JSON 으로. [결과 저장] 때도 `frame.json` 이 함께 저장됩니다.
- **거리 통계 기준점**: 거리별 타원도 표의 원점 (보통 품 입구 중심) 과 '앞쪽' 방향. 기울어진 프레임이면 입구가 향하는 각도로.
- 계산 뒤에 표를 고치면 버튼이 **'다시 계산하세요'** 로 바뀝니다 (그림의 장은 옛 결과).

**입력 오류로 알려 주는 것**: 길이 0, 두께 0, 계산 영역 밖으로 나간 막대, 셀에 비해 너무 얇은 막대
(아래 계단 근사 참고), 다른 막대에 가려져 유체에 닿지 않는 방사면, 켜진 방사면이 하나도 없음.

**기울어진 막대와 계단 근사**: 계산 격자는 x·y 방향 정사각형이라 기울어진 막대는 계단 모양으로 표현됩니다.

- 틈 방지: 막대 두께가 셀 크기 × max(|cos θ|, |sin θ|) 보다 두꺼우면 계단 사이로 물이 새는 틈이 생기지 않음이
  보장됩니다 (91 개 각도로 검사). 이보다 얇으면 오류로 알립니다. 셀 크기는 파장/(파장당 셀 수) 입니다.
- 정확도 (길이 8λ 기울인 피스톤, 0~75°): 진폭 오차 1% 이내, 에너지 흐름 방향 오차 ≤ 3° (파장당 셀 20) / ≤ 1.1° (40),
  계단 때문에 생기는 가짜 타원도 ≤ 0.05 (20) / ≤ 0.023 (40). 셀을 두 배로 늘리면 오차가 반으로 줍니다.
- 그래서 **기울어진 막대 근처의 e < 0.05 는 격자 오차일 수 있습니다.** 중요한 결론은 '파장당 셀 수' 를 30~40 으로 올려
  값이 같은지 확인하세요 (계산 시간은 약 2~4배).

### 주의할 점

- **공진**: 판 사이 간격 D 에서 f ≈ m·c/(2D) (횡모드 차단 주파수, D = 1 m 이면 750 Hz 의 배수) 근처 (간격의 15% 안) 이면 품 안에 갇힌 모드가
  공진해 압력이 수십 배 커집니다 (3000 Hz 에서 약 270 bar). 손실이 없는 이상 모델이라 과장되며, 실제로는 구조 손실·점성이
  제한합니다. 화면에 경고가 뜹니다.
- **음압 크기**: 물에서 변위 10 µm 는 2.7 kHz 에서 이미 수 bar 입니다. 선형 계산 자체는 유효하지만 실제 물에서는
  수심에 따른 정수압을 넘으면 캐비테이션이 생깁니다. 진폭을 줄여도 L, e, T 는 바뀌지 않습니다 (선형).
- **거리 구간 표의 회색 행**: 계산 영역이 그 거리의 반고리를 다 덮지 못해 모서리 방향만 표본이 된 구간입니다.
  비교하지 마세요. 더 멀리 보려면 계산 영역을 넓히세요.
- **2D 한계**: 2D 에서는 원거리 진폭이 1/√r, 실제 3D 품(z 방향으로도 유한) 에서는 1/r 로 줄어듭니다. 타원도가
  1/(kr) 로 줄어드는 성질은 두 경우 모두 같으므로 결론의 방향(밖으로 갈수록 직선 진동)은 같을 것으로 예상하지만,
  3D 로는 계산해 확인하지 않았습니다.
- 형상 치수가 셀 크기의 배수가 아니면 격자에 맞춰 이동하며, 경고가 뜹니다.

## 6. 한계

- 엔진 A 는 무한 평면파(와 그 합인 가우시안 빔)만 다룹니다. 반사, 경계, 산란은 엔진 B (2D) 에서만 다루며,
  감쇠와 비선형 효과는 두 엔진 모두 없습니다.
- 소진폭 선형 가정: 실제 변위가 파장의 수 % 를 넘는 큰 진폭에서는 맞지 않습니다.
- 지표는 선택한 시간창의 평균입니다. 맥놀이가 있으면 순간 궤적과 다릅니다.
- 결과는 입력한 소스 조건(방향, 위상, 주파수)에서의 결과이며, 다른 조건으로 일반화할 때는 따로 확인해야 합니다.

| 백신이 exe 를 차단/삭제 | PyInstaller 로 만든 서명 없는 exe 의 **오탐**이 흔합니다. 소스에서 직접 빌드한 파일이면 백신 예외에 폴더를 추가하세요. 그래서 기본 배포를 실행 속도와 오탐 면에서 유리한 폴더(onedir) 형식으로 했습니다 |
| "Windows 의 PC 보호" (SmartScreen) | 서명되지 않은 exe 라서 뜹니다. [추가 정보] → [실행] |
| 실행 후 아무 창도 안 뜸 / 갑자기 꺼짐 | 로그 확인: `%LOCALAPPDATA%\polarsim\logs\polarsim.log` (탐색기 주소창에 붙여넣기) |
| 3D 창이 안 열림 / 3D 소나 화면이 비거나 검음 | OpenGL 2.0 미지원 환경 (원격 데스크톱, 가상머신, 오래된 드라이버). PowerShell 에서 `.\polarsim.exe --software-gl` 로 실행하면 소프트웨어 OpenGL 로 그립니다 (조금 느림) |

| 화면이 흐리거나 너무 작음 | 고해상도 배율은 Windows 설정을 따릅니다. 앱 속성 → 호환성 → 높은 DPI 설정에서 조정 가능 |

## 8. 자체 진단

명령 프롬프트(PowerShell)에서 `polarsim.exe --selftest 결과폴더` 로 실행하면 물리 검증과 프리셋 3종 계산, 저장을
자동으로 수행하고 `결과폴더\selftest_report.txt` 와 화면 캡처를 남깁니다. 모든 항목이 PASS 여야 정상입니다.
3D 소나 탭도 작은 격자로 계산해 회전 검증, 정상상태, 저장, **3D 화면이 실제로 그려지는지** (그려진 픽셀 비율과 OpenGL 렌더러 이름) 를 확인합니다.
